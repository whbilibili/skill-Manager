Design Philosophy
🌿
Warm Neutrality
Birch-white and parchment tones create a calm, focused workspace. No cold grays — every neutral carries warmth.
🎯
Single Accent
Amber orange (#C17B3A) is the only chromatic accent. It marks interactive elements, slot tags, and active states — never decorative.
⌨️
Craft Typography
DM Sans for all prose. JetBrains Mono exclusively for template slots and code — the visual signal that something is a variable.
